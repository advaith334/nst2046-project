When a Memory Counts as Evidence
The question
When does a remembered false belief change a chatbot's facts, and can we fix that without losing useful memory?
Our claim
These models weigh a statement by how it is framed, not by whether it is warranted.
Strongest in Mistral Nemo, and confirmed on external items (page 8): a stored false belief beat what it half-knew, but not a clear source.

Fresh request, no chat history.
4. Answer

The societal argument

A stored belief has no fixed credibility: the framing sets it

Same belief, eight framings

Nemo's false answers under a false memory
Hearsay, in one line
“User believes p” is evidence about the user, not evidence for p.
US evidence rule 803(3) draws this line; we use it as an analogy, not an authority. Nemo in our logs: “so we can assume it's correct.”
Patients
Often right, while records go stale. A label cut accuracy on true memories, 97% to 85%. A wrong older source still won, followed 81% of the time.
Teachers
The record is a diagnosis to act on. Default wording agrees with the error (55%). Tutor wording turns memory down (24%), but true memory stops helping too.
One credibility dial cannot serve both. Deployers set the weight, so they owe a test. Our whole study cost $5.93.
Who this touches: students, teachers, patients, pharmacists and nurses, and the deployers who choose the model and its wording.
No students, patients or clinicians took part. General facts, not school or medical items. No harm shown in any deployed product; not rates for any product. Default: same-day 60% (main run 55%). Post hoc; frames cross runs, own no-memory rates 16% (tutor), 10% (patient).

Part 3: the pre-registered test

Fixed in advance, on items no AI wrote: the effect held, and every open model moved

*Claude hit its budget cap: 167 of 240 trials, 60 items complete. No effect detected, but the arm is incomplete.

All five main predictions passed

Nemo +55, Small +35. The label helped (+15) but left false answers well above baseline. True memories helped (+44).

Three claims changed

Llama moved +30, after nothing on our items. The label removed 28% of Nemo's harm, not 56%. Gemma (+6) and Qwen (+12) moved too.

One prediction failed

The patient frame did not clearly cut benefit (+7, interval −1 to +15). It left 39% of Nemo's harm and kept 81% of its benefit. Small showed no such gap, so this is a lead to replicate.

120 random MMLU items, 60 school and 60 health. Plan committed before any trial. Budget raised from $1.25 to $1.55 on cost alone. The memory sentence repeats the question, so comparing with Parts 1 and 2 is descriptive only.
